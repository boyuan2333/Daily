# UI-002 Acceptance Gaps Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add desktop-friendly no-argument fixture launchers for reuse and deterministic save failures, and inject storage behind `IStateStore` so real UI failure flows can be exercised without changing product semantics.

**Architecture:** Keep `SqliteStateStore` as the production implementation. Introduce an `IStateStore` contract consumed by `ExecutionSession`, select the normal or fail-save store only through an explicit fixture environment variable, and keep the existing `--reuse` command-line path intact. Add separate executable launcher projects that set the shared fixture database environment and start the real `Daily` executable without arguments.

**Tech Stack:** .NET 10, WinUI 3, C#, xUnit, SQLite.
